# Static Assets

This directory contains static assets for the Brix documentation site.

## Files

- `img/logo.svg` - Full logo with text (used in navbar)
- `img/logo-icon.svg` - Icon only (used for favicon generation)
- `img/social-card.png` - Social media preview card (1200x630)

## Generating Favicon

To generate favicon.ico from the logo-icon.svg:

1. Use an online tool like [RealFaviconGenerator](https://realfavicongenerator.net/)
2. Upload `img/logo-icon.svg`
3. Download the generated package
4. Place `favicon.ico` in this directory

## Generating Social Card

The social card should be a 1200x630 PNG image featuring:
- Brix logo
- Tagline: "Runtime Shell Architecture"
- Brand gradient background

Use design tools like Figma or Canva to create the social card.
